# PART 18 — SECURITY REQUIREMENTS

Treat this as a real commercial licensing system.

Implement strong security practices:

* HTTPS in production
* rate limiting
* input validation
* SQL injection protection through Prisma
* secure password hashing
* protected admin endpoints
* secure secrets through environment variables
* no database credentials in frontend
* no private signing keys in desktop app
* no secrets committed to Git
* CORS configured correctly
* Helmet/security headers
* audit logging
* device ID hashing
* replay protection where appropriate
* license activation rate limiting
* careful error messages that don't leak internal information

Do NOT promise that the `.exe` is "uncrackable".

Instead, design the system so that copying the installer alone is not enough to obtain a working licensed installation.

The server-side license authority, device binding, signed responses, and protected secrets should be the security foundation.
