The License API must provide at minimum:

POST /license/activate
POST /license/validate
POST /license/deactivate-device

Activation must:

1. Receive license key
2. Receive device ID
3. Find license in Neon
4. Verify license status
5. Verify expiration
6. Verify product
7. Check device limit
8. Bind device if allowed
9. Record activation event
10. Return a signed activation response

Validation must:

- verify license
- verify expiration
- verify device binding
- update lastSeen
- record validation event
- return signed response

Never put the License API's private signing secret inside the desktop application.
